---

## 1. 專案核心定位

- **App 名稱**：ChaosRegistry（不理性登記處 / 假投票人）
- **Slogan**：30 秒發起話題，全台幫你投票 + 留言激辯
- **目標用戶**：台灣為主，喜歡輕鬆、荒謔、時事、生活議題投票的人
- **核心價值**：快速、有趣、不理性也能認真投票，製造即時參與感與成就感

---

## 2. 鐵律（必須 100% 遵守）

1. **最小改動原則**：只改 UI 文案、顯示邏輯、彈窗、參數配置。**絕不新增複雜新功能**（避免審核風險）。
2. **新用戶優先**：新用戶 60 秒內必須知道怎麼玩 + 立刻有成就感。
3. **多語言友好**：所有文案務必準備 繁中 / 簡中 / English / 日本語。
4. **語氣原則**：輕鬆荒謔，但不低俗。
5. **輸出格式**：每次都給「立即可執行版」+「工程師規格描述」。

---

## 3. 目前共識版本（2026/05/21）

### Onboarding - 大型動畫按鈕強引導（最終版）

- **觸發條件**：僅新註冊且尚未發過主題的用戶
- **位置**：首頁完全蓋住原本的「發起主題」按鈕
- **主要文案**（單一句，大字置中）：

| 語言 | 文案 |
|------|------|
| 繁中 | 30 秒發起話題 馬上來試試！ |
| 簡中 | 30 秒发起话题 马上来试试！ |
| English | Create a topic in 30 seconds, Try now! |
| 日本語 | 30秒で話題作成 今すぐ試してみよう！ |

- **流程**：
  1. 新用戶開 App → 顯示大型脈動動畫按鈕
  2. 點擊 → 跳發文頁面（可選預填「這是我第一次發話題，大家來投票吧！」）
  3. 發文成功 → 走現有流程跳任務頁面領獎勵
  4. 下次開 App 自動隱藏，恢復原本按鈕

### 新用戶激勵（最終採用方案2）

- 註冊 / 首次登入 → 自動贈送 **200 代幣**（`reason = 'new_user_welcome_bonus'`）
- 首次發主題：盡量走免費或大幅降低門檻（後端可再優化）
